Splunk Enterprise · Boss of the SOC v3

Suspicious Shortcut
Investigation

Read the Splunk investigation on GitHub

I used SPL to investigate a simulated Symantec alert for a Windows shortcut. Starting with 67 filename matches, I identified duplicate Microsoft 365 audit records by ID and correlated the OneDrive upload with Sysmon file activity and Symantec’s reported deletions.

Shortcut execution remained unconfirmed after I reviewed the executable, parent process, and command line in all 50 Sysmon process-creation records returned for the 30-minute window.

Process-creation search

This query checks Sysmon Event ID 1 for BGIST-L. Run it with the Splunk user timezone set to UTC.

index=botsv3 "BGIST-L" sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational"
earliest="08/20/2018:09:45:00" latest="08/20/2018:10:15:00"
| regex "<EventID>1</EventID>"
| sort _time
| rex "Name='Image'>(?<Program>[^<]*)"
| rex "Name='ParentImage'>(?<Parent>[^<]*)"
| rex "Name='CommandLine'>(?<CommandLine>[^<]*)"
| table _time Program Parent CommandLine
